# 🌿 弹幕生态系统 · Danmaku Ecosystem

> 直播互动弹幕游戏：观众发弹幕驱动两个生物群落实时对抗

## 这是什么

观众在直播间发弹幕（如"下雨"、"投放狼"、"地震"），游戏自动匹配为生态事件，两个生物群落（从8种中随机选2种）在 2.5D 等距视角沙盘上实时演化对抗。30分钟后以生态健康度评分决出胜负。

**核心卖点：**
- 观众零门槛参与，发弹幕就能影响游戏
- 沙盘自动演化，即使不参与也有看头（食物链、繁殖、迁徙、死亡）
- 用户数据持久化，等级/权重系统带来长期粘性
- 冷启动不冷场：无人时 AI 自动驱动

## 游戏机制

### 8 种生物群落
| 群落 | 特色 | 特殊生物 |
|------|------|---------|
| 🏔️ 山脉 | 矿石泉水 | 雪豹、鹰 |
| 🌊 湖泊 | 水草珍珠 | 蜻蜓、水獭 |
| 🌴 雨林 | 果实药草 | 巨嘴鸟、美洲豹 |
| 🏜️ 沙漠 | 石油绿洲 | 沙虫、耳廓狐 |
| 🌋 火山 | 黑曜石硫磺 | 凤凰、熔岩龙 |
| 🧊 冰原 | 冰晶矿脉 | 独角鲸、北极熊 |
| 🌾 草原 | 牧草蜂巢 | 蝴蝶、野牛 |
| 🏝️ 海岛 | 贝壳椰子 | 海豚、鲨鱼 |

### 弹幕→事件映射
```
观众发: "下雨"    → 🌧️ 天气变为降雨（植物生长 +50%）
观众发: "投放狼"  → 🐺 出现 2 只狼（开始捕食食草动物）
观众发: "地震"    → 🌋 损失 15% 人口（需 Lv.10+）
观众发: "进化"    → 🧬 随机物种变异，数量 +50%
观众发: "凤凰"    → 🔥 出现 1 只凤凰（终极生物，需高等级）
```

### 评分公式
```
进化度 = 物种多样性×10 + 生态平衡×50 + 总人口(上限500) + 变异数×20 + 存活分钟×5
```

### 冷启动策略
| 观众数 | AI 行为 |
|--------|---------|
| 0 人 | AI 每 30 秒自动触发小事件 |
| 1-3 人 | AI 辅助，降低频率 |
| 5+ 人 | 完全由观众驱动 |
| 20+ 人 | 投票模式（多数弹幕决定） |

## API 端点

| 路由 | 方法 | 说明 |
|------|------|------|
| `/api/stream` | GET | SSE 实时推送（主通信通道） |
| `/api/state` | GET | 当前游戏完整状态 |
| `/api/join` | POST | 加入阵营 `{faction: "mountain"}` |
| `/api/event` | POST | 触发事件 `{faction, text, name, platform, platformUid}` |
| `/api/leaderboard` | GET | 排行榜 `?limit=10` |
| `/api/user/:platform/:uid` | GET | 查询用户详情 |
| `/api/gift` | POST | 记录礼物 `{platform, platformUid, nickname, giftName, giftValue}` |
| `/api/history` | GET | 历史对局记录 |

## 技术决策

| 决策 | 原因 |
|------|------|
| SSE 而非 WebSocket | 更简单可靠，单向推送足够 |
| 原生 http 而非 Express | 减少依赖，MVP 足够 |
| 原生 Canvas 而非 PixiJS | 控制力强，包体小 |
| SQLite 而非 PostgreSQL | 单机部署简单，后续可迁移 |
| 竖屏布局 | 匹配手机直播场景 |
