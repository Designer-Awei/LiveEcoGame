# 🌿 LiveEcoGame · 弹幕生态系统

> 直播互动弹幕游戏：两个生态各自发育，观众弹幕影响生态走向，比拼最终分数

## 一句话介绍

观众在直播间发弹幕（如"下雨"、"投放狼"、"地震"），游戏自动匹配为生态事件。两个生物群落在 2.5D 等距沙盘上**各自独立发育**，互不干扰，受弹幕影响生态走向。15分钟后比拼总分，分数高者获胜。界面中央有**实时胜率条**，随时显示两边获胜概率。

## 快速开始

```bash
# 前置：Node.js >= 22
npm install
npm start
# 浏览器打开 http://127.0.0.1:4400
# 调试控制台 http://127.0.0.1:4400/debug.html
```

## 核心玩法

### 核心玩法
- **各自发育**：两个生态系统独立演化，互不直接攻击
- **弹幕影响**：观众发弹幕触发天气/生物/灾害等事件，影响自己支持的生态
- **分数决胜**：最终比拼生态健康度总分，不是直接对抗
- **胜率条**：界面中央实时显示两边获胜概率（Sigmoid模型，早期不确定性大，后期趋于确定）
- **对战轮换**：自动避免重复组合，确保8种群落均匀出场

### 事件触发规则
- **普通事件**（天气/基础生物/祝福/资源）：任何用户可触发，但有**冷却时间**
- **冷却机制**：每种类别独立冷却（天气10秒、生物15秒、祝福30秒……）
- **权重加速冷却**：权重越高冷却越短（权重2000时冷却降至最短）
- **防刷屏**：同一用户同一类别在冷却期内无法重复触发

### 事件分类
| 分类 | 示例 | 基础冷却 | 最短冷却 | 门槛 |
|------|------|---------|---------|------|
| 天气 | 下雨、晴天、暴风雪 | 10s | 3s | 无 |
| 生物 | 投放兔子、狼、鹰 | 15s | 5s | 无 |
| 祝福 | 神圣祝福 | 30s | 10s | 无 |
| 资源 | 丰收、资源涌现 | 20s | 8s | 无 |
| 灾害 | 地震、洪水、瘟疫 | 60s | 20s | Lv.10+ |
| 进化 | 进化突变 | 45s | 15s | Lv.5+ |
| 传说 | 狮子、熊猫、鲨鱼 | 30s | 10s | Lv.5+ (低概率) |
| 神话 | 龙、凤凰 | 120s | 60s | Lv.20+ (极低概率) |
| 点赞 | 发送"666"/点赞 | 5s | 2s | 无 |

### 稀有生物
- **传说生物**（狮子/熊猫/鲨鱼等）：Lv.5+ 用户可触发，但有概率限制
- **神话生物**（龙/凤凰）：Lv.20+ 用户可触发，仅 **5% 概率成功**（给低等级玩家偶尔惊喜）
- 低等级用户碰运气触发稀有事件时，冷却不受权重缩短

## 评分公式
```
进化度 = 物种多样性×10 + 生态平衡×50 + 总人口(上限500) + 变异数×20 + 存活分钟×5
```

**平衡性设计**（2026-10更新）：
- 所有群落生产者参数归一化（maxPop=120, growth=0.10），消除阵营间先天差异
- 每局随机"生态活力系数"（0.85~1.15），增加单局变化但长期保持50%胜率
- 温度惩罚放宽（<0°C ×0.6，>40°C ×0.7），冬季惩罚放宽
- 1000局模拟验证：所有群落胜率44%~55%，平均50.0%

## 冷启动策略
| 观众数 | AI 行为 |
|--------|---------|
| 0 人 | AI 每 30 秒自动触发小事件 |
| 1-3 人 | AI 辅助，降低频率 |
| 5+ 人 | 完全由观众驱动 |
| 20+ 人 | 投票模式（多数弹幕决定） |

## API 端点

### 游戏 API
| 路由 | 方法 | 说明 |
|------|------|------|
| `/api/stream` | GET | SSE 实时推送（主通信通道） |
| `/api/state` | GET | 当前游戏完整状态 |
| `/api/join` | POST | 加入阵营 `{faction}` |
| `/api/event` | POST | 触发事件 `{faction, text, name, platform, platformUid}` |
| `/api/leaderboard` | GET | 排行榜 `?limit=10` |
| `/api/user/:platform/:uid` | GET | 查询用户详情 |
| `/api/gift` | POST | 记录礼物 |
| `/api/history` | GET | 历史对局记录 |

### 调试 API
| 路由 | 说明 |
|------|------|
| `/debug.html` | 调试控制台（浏览器） |
| `/api/debug/state` | 完整调试状态（游戏+冷却+生物） |
| `/api/debug/trigger?faction=0&type=weather&name=降雨` | 直接触发事件（绕过冷却） |
| `/api/debug/setweight?weight=1000` | 设置调试用户权重 |
| `/api/debug/reset` | 重置游戏 |

## 视觉渲染（v2）
- **精细地形**：瓦片渐变纹理、噪点、高度边缘高光、水面波纹
- **8种群落专属装饰**：松树/水晶/荷花/巨树/仙人掌/岩浆池/冰屋/棕榈树等30+种
- **环境氛围粒子**：萤火虫、雪花、沙尘、气泡、火星、蝴蝶（按群落自动匹配）
- **灾害动效**：地震屏幕震动+裂缝、火山喷发火焰粒子、瘟疫迷雾、洪水光效
- **特殊物种光效**：传说/神话生物（龙/凤凰/海豚等）带金色光晕
- **夜空**：月亮光晕+30颗闪烁星星

## 技术决策
| 决策 | 原因 |
|------|------|
| SSE 而非 WebSocket | 更简单可靠，单向推送足够 |
| 原生 http 而非 Express | 减少依赖，MVP 足够 |
| 原生 Canvas 而非 PixiJS | 控制力强，包体小 |
| 竖屏布局 | 匹配手机直播场景 |
| 程序化渲染 | 无需外部素材即可运行 |
