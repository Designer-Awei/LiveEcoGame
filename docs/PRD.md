> 版本：v0.2 | 更新日期：2026-10-03 | 作者：Awei + Hermes

## 1. 产品概述

### 1.1 产品定位
**弹幕生态系统**是一款面向直播平台的AI互动弹幕游戏。观众通过发送弹幕影响一个实时演化的生态沙盘，两个生物群落左右对抗，最终以生态健康度评分决出胜负。

### 1.2 核心价值
- **观众**：零门槛参与，发弹幕就能影响游戏，历史数据持久化带来成就感
- **主播**：自动化运行，无需手动操作，观众留存+付费转化
- **平台**：用户粘性提升，礼物消费新场景

### 1.3 目标用户
- 直播间观众（18-35岁，手游/休闲游戏用户）
- B站/抖音/快手游戏主播
- 弹幕互动游戏爱好者

## 2. 核心玩法

### 2.1 游戏流程
```
开局：随机抽取2个生物群落（从8个中选）
  ↓
观众发弹幕选阵营（如「山脉」「沙漠」）
  ↓
弹幕触发事件（下雨/投放生物/地震/进化...）
  ↓
沙盘自动演化（食物链、繁殖、迁徙、死亡）
  ↓
每60秒全局随机事件（无人时保证画面活跃）
  ↓
终局（30分钟）：生态评分结算 → 排行榜更新
```

### 2.2 生物群落（8种，每局随机2种）

| 群落 | 初始生物 | 特殊资源 | 天敌 |
|------|---------|---------|------|
| 🏔️ 山脉 | 山羊、鹰、雪兔 | 矿石、泉水 | 雪崩、山火 |
| 🌊 湖泊 | 鱼、水鸟、青蛙 | 水草、珍珠 | 干旱、污染 |
| 🌴 雨林 | 猴子、蛇、鹦鹉 | 果实、药草 | 瘟疫、洪水 |
| 🏜️ 沙漠 | 蜥蜴、蝎子、骆驼 | 石油、绿洲 | 沙尘暴、酷热 |
| 🌋 火山 | 火蜥蜴、熔岩虫 | 黑曜石、硫磺 | 喷发、地震 |
| 🧊 冰原 | 北极熊、企鹅、海豹 | 冰晶、矿脉 | 暴风雪、冰裂 |
| 🌾 草原 | 牛群、狼、老鹰 | 牧草、蜂巢 | 蝗灾、野火 |
| 🏝️ 海岛 | 海龟、螃蟹、信天翁 | 贝壳、椰子 | 海啸、台风 |

### 2.3 事件系统（双层）

**弹幕事件**（观众触发）：
- 天气：下雨、晴天、暴风雪、干旱、热浪
- 生物投放：兔子、狼、鹰、鹿、鱼、蛇、蝴蝶、猴子、狮子、恐龙、凤凰
- 灾害：地震、洪水、瘟疫、蝗灾、火山喷发、山火
- 增益：进化突变、神圣祝福、资源涌现

**全局事件**（自动触发，每60秒）：
- 天气变化、季节更替、小型灾害
- 无人时保证画面持续活跃

### 2.4 评分系统
```
进化度 = 物种多样性×10 + 生态平衡×50 + 总人口(上限500) + 变异数×20 + 存活分钟×5
```

## 3. 用户系统

### 3.1 用户身份
- 平台账号自动绑定（B站UID/抖音UID）
- 无需注册，首次发弹幕自动创建档案
- 跨直播间数据复用

### 3.2 等级体系

| 等级 | 累计权重 | 称号 | 特权 |
|------|---------|------|------|
| Lv.1 | 0 | 新芽观察者 | 基础操作 |
| Lv.5 | 100 | 生态学徒 | 可投放稀有生物 |
| Lv.10 | 500 | 自然守护者 | 可触发小型灾害 |
| Lv.20 | 2000 | 生态大师 | 可触发全局事件 |
| Lv.30 | 5000 | 钻石守护者 | 可触发终极事件 |
| Lv.50 | 15000 | 创世神 | 自定义事件+专属称号 |

### 3.3 权重计算
```
总权重 = 基础权重(等级×10) + 消费权重(礼物×10) + 活跃权重(弹幕×0.1+局数×2) + 荣耀权重(连胜×5)
```

### 3.4 权重影响
- 事件触发概率：基础30% + 等级×10%（最高100%）
- 事件强度倍率：1x / 1.5x / 2x / 3x / 5x / 10x
- 事件类型解锁：低等级只能操作天气，高等级可触发灾害/终极事件

## 4. 商业模式

### 4.1 免费层
- 基础游戏参与（选阵营、发弹幕触发天气/基础生物）
- 历史数据查看
- 排行榜浏览

### 4.2 付费层（通过礼物触发）
| 礼物 | 效果 | 价格区间 |
|------|------|---------|
| 小礼物 | +10权重，触发基础事件 | 1-5元 |
| 中礼物 | +100权重，触发稀有事件 | 10-50元 |
| 大礼物 | +500权重，触发终极事件+全服公告 | 100-500元 |
| 专属礼物 | 自定义事件+专属称号 | 500元+ |

### 4.3 主播订阅
- 基础版：免费，单直播间
- 专业版：月付，跨直播间数据+高级分析
- 企业版：定制，API接入+白标

### 4.4 奖池机制
- 主播设置奖池（生态点/虚拟货币）
- 每局MVP瓜分奖池
- 新主播首周翻倍

## 5. 技术架构

### 5.1 系统架构
```
┌──────────────────────────────────────────┐
│              中心API服务                   │
│         (用户数据+权重+排行榜)             │
├──────────────────────────────────────────┤
│  SQLite/PostgreSQL                        │
│  users / gifts / games / actions          │
└──────────────────────────────────────────┘
     ↑           ↑           ↑
  主播A        主播B        主播C
  (本地Node)   (本地Node)   (本地Node)
     ↑           ↑           ↑
  弹幕流       弹幕流       弹幕流
```

### 5.2 技术栈
- **后端**：Node.js 24.x + SQLite
- **前端**：HTML5 Canvas + CSS + 原生JS
- **通信**：SSE (Server-Sent Events)
- **渲染**：程序化像素画 + Canvas动画
- **弹幕**：B站/抖音开放平台API

### 5.3 端口规划
| 端口 | 用途 |
|------|------|
| 4400 | 游戏管理页面 |
| 4401 | 游戏画面（OBS Browser Source） |
| 4402 | 中心API服务 |

### 5.4 数据存储
- **本地**：SQLite（单主播部署）
- **云端**：PostgreSQL（多主播共享）
- **缓存**：Redis（高频访问数据）

## 8. 竞品分析

| 竞品 | 类型 | 优势 | 劣势 |
|------|------|------|------|
| 羊狼拉力赛 | 拉力赛 | 用户数据持久化，等级系统 | 玩法单一 |
| 弹幕赛车 | 竞速 | 即时反馈，视觉刺激 | 太常见，无深度 |
| 弹幕大乱斗 | 格斗 | 对抗性强 | 门槛高 |

**我们的差异化：**
- 生态模拟深度（食物链、进化、天气系统）
- 策略性（不是纯手速，是弹幕决策）
- 观賞性（沙盘自演化，即使不参与也有看头）
- 数据深度（多维度权重，不是单一积分）

## 9. 风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 冷启动无观众 | 画面空洞 | AI自动演进+模拟观众 |
| 作弊/刷权重 | 破坏公平 | 权重来源验证+异常检测 |
| 主播不理解 | 推广困难 | 一键部署+教程视频 |
| 弹幕延迟 | 体验差 | 本地缓存+预测执行 |
